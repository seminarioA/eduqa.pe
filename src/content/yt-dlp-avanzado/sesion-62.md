# La política es explícita

`CONTRIBUTING.md` prohíbe estrictamente el uso de LLMs, agentes u otras herramientas de IA para cualquier contribución al proyecto.

> Doc: [NO AI / NO LLM POLICY](https://github.com/yt-dlp/yt-dlp/blob/master/CONTRIBUTING.md#no-ai--no-llm-policy)

# Issues y bug reports

No se permite utilizar IA para redactar o producir issues ni bug reports.

# Patches y pull requests

La prohibición incluye código, patches, pull requests y sus descripciones.

# Comentarios y reviews

Tampoco se permite IA en comentarios del issue tracker ni en comentarios de code review.

# Traducciones

La política prohíbe IA para traducciones. El proyecto prefiere inglés, pero acepta que una persona escriba en su idioma nativo y que otras personas traduzcan con sus propias herramientas.

# Consecuencia documentada

La organización advierte que una persona que viole la política puede ser bloqueada sin aviso previo.

```opcion-multiple
# Enunciado
¿Cuál de estos usos de IA está permitido por la política de contribución de yt-dlp?

# Opciones
- Redactar un issue
- Generar un patch
- Escribir un comentario de review
- Ninguno de los anteriores

# Correcta
4

# Explicación
La política prohíbe IA/LLM para cualquier clase de contribución al proyecto.

# Pista
La prohibición cubre issues, código y comentarios.
```

# Alcance de este curso

Estudiar la política, el código y la arquitectura no constituye por sí mismo una contribución al repositorio. Si el alumno decide abrir un issue, PR o comentario en yt-dlp, ese contenido debe producirse sin herramientas de IA.
