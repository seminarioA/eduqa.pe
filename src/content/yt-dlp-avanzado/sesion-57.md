# Alcance

El README separa estas opciones porque no están destinadas al usuario final.

> Doc: [Deprecated options — Developer options](https://github.com/yt-dlp/yt-dlp#developer-options)

# --test

Descarga únicamente una parte del vídeo para probar extractores.

```ejercicio
# Enunciado
Completa la opción destinada a una descarga parcial de testing.

# Plantilla
print("___")

# Esperado
--test

# Pista
El nombre coincide con «prueba» en inglés.
```

# --load-pages

Carga páginas previamente volcadas mediante `--write-pages`.

# --allow-unplayable-formats

Incluye formatos no reproducibles en el listado.

# --no-allow-unplayable-formats

Es el comportamiento predeterminado.

```ejercicio
# Enunciado
Completa la opción predeterminada que no incluye formatos no reproducibles.

# Plantilla
print("___")

# Esperado
--no-allow-unplayable-formats

# Pista
Niega allow-unplayable-formats.
```
