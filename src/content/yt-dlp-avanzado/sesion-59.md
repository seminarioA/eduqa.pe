# Sustitución por SponsorBlock

El soporte de SponSkrub fue retirado en favor de las opciones SponsorBlock.

> Doc: [Deprecated options — Sponskrub Options](https://github.com/yt-dlp/yt-dlp#sponskrub-options)

# --sponskrub

Su equivalente es `--sponsorblock-mark all`.

```ejercicio
# Enunciado
Completa el equivalente moderno de --sponskrub.

# Plantilla
print("--sponsorblock-mark " + "___")

# Esperado
--sponsorblock-mark all

# Pista
Marca todas las categorías.
```

# --no-sponskrub

Equivale a `--no-sponsorblock`.

# --sponskrub-cut

Equivale a `--sponsorblock-remove all`.

# --no-sponskrub-cut

Equivale a `--sponsorblock-remove -all`.

# Opciones sin equivalente

`--sponskrub-force`, `--no-sponskrub-force`, `--sponskrub-location` y `--sponskrub-args` no tienen equivalente aplicable.

```opcion-multiple
# Enunciado
¿Qué sistema reemplazó a SponSkrub en yt-dlp?

# Opciones
- SponsorBlock
- netrc
- PyInstaller
- WebPO

# Correcta
1

# Explicación
La sección de opciones deprecadas remite a SponsorBlock.

# Pista
Ya se cubrió en el nivel intermedio.
```
