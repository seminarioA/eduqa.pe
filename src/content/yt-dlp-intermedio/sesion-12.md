# -q y --quiet

`-q` es la forma corta de `--quiet`. Reduce la salida normal de yt-dlp.

> Doc: [Verbosity and Simulation Options — --quiet](https://github.com/yt-dlp/yt-dlp#verbosity-and-simulation-options)

```ejercicio
# Enunciado
Completa la forma corta de --quiet.

# Plantilla
print("yt-dlp " + "___")

# Esperado
yt-dlp -q

# Pista
Usa la inicial de quiet.
```

# --no-quiet

`--no-quiet` revierte el modo silencioso.

```ejercicio
# Enunciado
Completa la opción que desactiva quiet.

# Plantilla
print("___")

# Esperado
--no-quiet

# Pista
Niega --quiet.
```

# --no-warnings

`--no-warnings` suprime mensajes de advertencia. Ocultar una advertencia no corrige la condición que la originó.

```ejercicio
# Enunciado
Completa la opción que suprime advertencias.

# Plantilla
print("___")

# Esperado
--no-warnings

# Pista
La palabra clave es `warnings`.
```
