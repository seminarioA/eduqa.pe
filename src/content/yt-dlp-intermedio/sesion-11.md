# --write-link

`--write-link` escribe un acceso directo de Internet adecuado para la plataforma.

> Doc: [Internet Shortcut Options — --write-link](https://github.com/yt-dlp/yt-dlp#internet-shortcut-options)

```ejercicio
# Enunciado
Completa la opción genérica de acceso directo.

# Plantilla
print("___")

# Esperado
--write-link

# Pista
Combina `write` y `link`.
```
