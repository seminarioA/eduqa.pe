# --write-subs

`--write-subs` escribe archivos de subtítulos disponibles.

> Doc: [Subtitle Options — --write-subs](https://github.com/yt-dlp/yt-dlp#subtitle-options)

```ejercicio
# Enunciado
Completa la opción que escribe subtítulos.

# Plantilla
print("___")

# Esperado
--write-subs

# Pista
Combina `write` y `subs`.
```

# --no-write-subs

`--no-write-subs` evita escribir subtítulos y es el comportamiento predeterminado.

```ejercicio
# Enunciado
Completa la opción predeterminada.

# Plantilla
print("___")

# Esperado
--no-write-subs

# Pista
Niega --write-subs.
```

# --write-auto-subs

`--write-auto-subs` escribe subtítulos generados automáticamente. Su alias es `--write-automatic-subs`.

```ejercicio
# Enunciado
Completa la opción principal para subtítulos automáticos.

# Plantilla
print("___")

# Esperado
--write-auto-subs

# Pista
Incluye `auto`.
```

# --no-write-auto-subs

`--no-write-auto-subs` evita escribir subtítulos automáticos y es el valor predeterminado.

# --list-subs

`--list-subs` enumera los subtítulos disponibles y simula salvo que se use `--no-simulate`.

```ejercicio
# Enunciado
Completa la opción que lista subtítulos.

# Plantilla
print("___")

# Esperado
--list-subs

# Pista
Empieza con `--list-`.
```
