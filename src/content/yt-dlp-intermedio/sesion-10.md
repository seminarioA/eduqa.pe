# --write-thumbnail

`--write-thumbnail` guarda una miniatura en disco.

> Doc: [Thumbnail Options — --write-thumbnail](https://github.com/yt-dlp/yt-dlp#thumbnail-options)

```ejercicio
# Enunciado
Completa la opción que guarda una miniatura.

# Plantilla
print("___")

# Esperado
--write-thumbnail

# Pista
Combina `write` y `thumbnail`.
```

# --no-write-thumbnail

`--no-write-thumbnail` evita guardar miniaturas.

```ejercicio
# Enunciado
Completa la opción negativa.

# Plantilla
print("___")

# Esperado
--no-write-thumbnail

# Pista
Niega la opción anterior.
```

# --write-all-thumbnails

`--write-all-thumbnails` guarda todas las miniaturas disponibles.

```ejercicio
# Enunciado
Completa la opción que guarda todas las miniaturas.

# Plantilla
print("___")

# Esperado
--write-all-thumbnails

# Pista
Incluye la palabra `all`.
```

# --list-thumbnails

`--list-thumbnails` enumera las miniaturas disponibles.

```bash !sin-consola
yt-dlp --list-thumbnails "URL"
```

```ejercicio
# Enunciado
Completa la opción de listado.

# Plantilla
print("___")

# Esperado
--list-thumbnails

# Pista
Empieza con `--list-`.
```
