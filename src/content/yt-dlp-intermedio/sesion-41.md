# -k y --keep-video

`-k` es la forma corta de `--keep-video`. Conserva el archivo de vídeo intermedio después del postprocesamiento.

> Doc: [Post-Processing Options — --keep-video](https://github.com/yt-dlp/yt-dlp#post-processing-options)

```ejercicio
# Enunciado
Completa la forma corta de --keep-video.

# Plantilla
print("yt-dlp " + "___")

# Esperado
yt-dlp -k

# Pista
Usa una k minúscula.
```

# --no-keep-video

`--no-keep-video` elimina el archivo intermedio después del postprocesamiento y es el comportamiento predeterminado.

```ejercicio
# Enunciado
Completa la opción predeterminada.

# Plantilla
print("___")

# Esperado
--no-keep-video

# Pista
Niega --keep-video.
```

# --post-overwrites

`--post-overwrites` permite sobrescribir archivos producidos por postprocesamiento y es el comportamiento predeterminado.

```ejercicio
# Enunciado
Completa la opción que permite sobrescritura postprocesada.

# Plantilla
print("___")

# Esperado
--post-overwrites

# Pista
Empieza con `--post-`.
```

# --no-post-overwrites

`--no-post-overwrites` evita sobrescribir archivos postprocesados existentes.

```ejercicio
# Enunciado
Completa la opción negativa.

# Plantilla
print("___")

# Esperado
--no-post-overwrites

# Pista
Niega --post-overwrites.
```
