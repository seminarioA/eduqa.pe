# --ap-mso

`--ap-mso MSO` recibe el identificador del multiple-system operator de Adobe Pass.

> Doc: [Authentication Options — --ap-mso](https://github.com/yt-dlp/yt-dlp#authentication-options)

```ejercicio
# Enunciado
Completa la opción que recibe el identificador MSO.

# Plantilla
print("___")

# Esperado
--ap-mso

# Pista
Termina en `mso`.
```

# --ap-username

`--ap-username USERNAME` recibe el usuario de la cuenta del proveedor.

```ejercicio
# Enunciado
Completa la opción de usuario del proveedor.

# Plantilla
print("___")

# Esperado
--ap-username

# Pista
Termina en `username`.
```

# --ap-password

`--ap-password PASSWORD` recibe la contraseña del proveedor. Si se omite, yt-dlp puede solicitarla interactivamente.

```ejercicio
# Enunciado
Completa la opción de contraseña del proveedor.

# Plantilla
print("___")

# Esperado
--ap-password

# Pista
Termina en `password`.
```
